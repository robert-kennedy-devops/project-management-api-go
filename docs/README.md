# Documentação

Esta pasta concentra materiais de apoio do projeto.

## E-book

O e-book gerado para estudo e distribuição deve ser salvo aqui com o nome:

```text
ebook_backend_junior_golang.pdf
```

Caso o upload direto do PDF pelo conector não esteja disponível, baixe o arquivo gerado localmente e faça o upload manual pela interface do GitHub.

## OpenAPI
